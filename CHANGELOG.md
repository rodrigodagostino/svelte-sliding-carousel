# CHANGELOG

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.4.1] (2026-11-24)

### Added

- Add `align` to control where active slide snaps.

### Fixed

- Prevent track transition on initial load when `align` is not `start`.

### Docs

- Prevent style overrides between demo pages.
- Rename `slides-per-view` routes.

## [0.4.0] (2026-11-24)

### Added

- Add `slidesPerView`.
- Add `'auto'` as option to `slidesPerView`.

### Docs

- Add more default slides to fixtures.

## [0.3.0] (2026-11-23)

### Added

- Add `autoplay`.

## [0.2.2] (2026-11-23)

### Added

- Add `gap` between slides.
- Allow slide `transition` customization.

## [0.2.1] (2026-11-23)

### Added

- Add `rewind` to loop.

### Docs

- Add **“With loop and rewind”** demo page.
- Change version number position in layout menu.

### Chores

- Add license.

## [0.2.0] (2026-11-23)

### Added

- Add opt-in infinite loop.

### Docs

- Add menu and controls to demo pages layout.
- Add **“With loop”** demo page.

## [0.1.0] (2026-08-29)

### Added

- Add carousel base structure and functionality.
- Add base styles.
- Expose components and base styles.

### Docs

- Add **“Basic”** demo page.
- Add base project info to README.
